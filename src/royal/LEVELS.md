# 개인용 레벨 데이터와 편집 규칙

이 캠페인은 공개 도움말에서 확인한 기믹을 사용해 만든 **개인용 레벨 구성**이다. 원작 전체 레벨 파일이나 난이도 공식을 확보한 것은 아니다.

## 구성

- **1–32:** 직접 정한 크기·형상·목표·이동 수·기믹 조합. 처음에는 색 수집, 이후 상자→선물→젤리→얼음→뻐꾸기→돌→다이너마이트를 경험한다. 이 등장 순서는 이 프로젝트의 튜토리얼이며 원작의 해금표가 아니다.
- **33–999999:** 레벨 번호를 시드로 한 재현 가능한 생성. 7–10열, 8–11행, 12가지 형상 계열을 조합한다. 상자·선물, 둥지, 얼음·폭발, 돌·폭발 등 여섯 조합 유형을 사용하고 목표는 실제 배치된 개체 수에서 도출한다.
- **12297:** 사용자가 확인한 영상의 9×11 보드 마스크와 2×2 다이너마이트·뻐꾸기 위치를 참조한 별도 재구성. 외곽과 기믹을 참고했지만 원작 시작 상태의 완전 복제는 아니다.

레벨마다 새 정의를 반환하므로 편집기에서 원본 배열을 변경해도 다른 세션의 캠페인은 변하지 않는다. 레벨 설계의 시드는 고정되며, 재도전 때 일반 블록을 새로 배치하는 정책은 게임 시작 옵션에서 별도로 정한다.

## 난이도

Normal, Hard, Super Hard, Extremely Hard의 태그는 원작의 공개 분류를 사용한다. **개별 태그 배치와 수치 조정은 개인용 설계**다. 원작이 특정 주기나 선형 공식으로 난도를 올린다고 가정하지 않는다.

초반 캠페인은 기믹 단독 학습과 복합 과제를 번갈아 배치한다. 생성 레벨은 크기·장애물 수·장애물 종류·이동 수가 함께 변한다. 장애물이 배치될 수 없으면 임의로 목표만 늘리지 않고 실제 배치 수로 목표를 계산한다. 자유로운 3×3 매치 공간 하나를 확보하고, 분리된 젤리 구역에는 각각 씨앗을 배치한다.

이는 구조적으로 불가능한 목표를 막는 기준이다. 모든 판을 제한 이동 안에 무부스터로 해결할 수 있다는 수학적 증명이나 원작과 동일한 성공률을 의미하지 않는다. 개인 설정에서 이동 수·도구를 조정할 수 있다.

## 레벨 12297 재구성의 근거와 차이

| 항목 | 적용 |
|---|---|
| 레벨 번호 | 사용자 설명 및 추가 사진의 12297 |
| 보드 | 9열×11행. 위 4행 전체, 아래 7행의 4·5열은 빈 공간 |
| 다이너마이트 | 4·5열 / 3·4행을 점유하는 2×2 개체, 재고 8 |
| 뻐꾸기 | 7·8열 / 3·4행을 점유하는 2×2 개체, 새 2 |
| 장난감 | 긴 선물상자 9개에 장난감 2개씩 배정, 총 18 |
| 젤리 | 보드 85칸 중 4칸을 칠한 상태로 시작, 남은 81칸 |
| 이동 | 개인 플레이용 32회. 영상의 22회나 사진의 9회는 남은 이동이므로 시작 이동으로 사용하지 않음 |
| 일반 블록 | 시드에 따른 새 배치. 영상의 정확한 원본 시작 배치가 아님 |

선물상자 위치·장난감 배분·시작 젤리 4칸·시작 이동은 플레이 가능한 재구성을 위해 정한 값이다. 영상의 중간 잔량을 원작의 최초 목표량이라고 주장하지 않는다. UI와 내보내기 데이터에 `reference-reconstruction` 출처를 유지한다.

## JSON 가져오기

`validateLevel`은 읽은 JSON 객체를 검증하고 새 배열·객체로 복사한다. 실패하면 `level` 없이 한국어 `errors`를 반환한다. 알 수 없는 속성은 제거해 숨기지 않고 오류로 표시한다.

- 형식 `version: 1`, 레벨 번호 1–999999, 보드 각 변 5–12칸(최대 144칸).
- 이름 1–80자, 설명 최대 1000자, 이동 1–200, 색상 3 또는 4, 시드 0–4294967295.
- 보드 마스크는 정확한 행·열 수의 0/1 문자열 배열.
- 최소 12개 유효 칸, 장애물을 제외하고 최소 9개 빈 칸, 일반 매치가 가능한 연속 칸이 필요.
- 장애물 ID 중복·점유 중복·보드 밖/빈 공간 배치 금지. 한 개체는 연결된 1–16칸. 내구도 1–12, 재고 1–100.
- 목표는 중복 없는 1–8개. 색 목표는 사용 가능한 색이어야 하며 아이템 목표량은 실제 재고보다 많을 수 없다.
- 젤리 목표는 시작 젤리가 있어야 하고, 미도포 칸 수를 초과할 수 없다. 분리된 보드마다 젤리 씨앗이 필요하다.
- 초기 블록은 보드 밖·장애물·다른 블록과 겹칠 수 없다. 특수 블록 종류는 정의된 다섯 방향/종류 값만 허용한다.

캠페인의 얼음은 세로 3칸·3회 타격으로 두며 타격할 때 끝 칸이 풀리는 길이형 기믹이다. 수집 목표에서 `box`, `ice`, `stone`은 개체 수이며 HP 합이 아니다. `gift.stock`은 파괴 시 나오는 장난감 수, `cuckoo.stock`은 남은 새, `dynamite.stock`은 남은 폭발 횟수다. `deriveGoals`는 이 실제 재고와 아직 칠하지 않은 젤리 칸으로 목표를 다시 계산한다. 장애물도 젤리도 없는 편집 보드는 왕관 20개 수집이 기본값이다.
