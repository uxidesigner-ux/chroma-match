# v7 버튼·블록·햅틱 개선

2026-11-23. 사용자가 보낸 레벨 4 화면의 도구 버튼과 이동·폭발의 촉감을 개선한 작업입니다.

## 화면과 동작

- 아이콘 이미지가 버튼 높이를 밀어 늘이던 원인을 제거했습니다. 도구 버튼은 좁은 iPhone과 가로 화면에서도 원형을 유지하며 금색 테두리, 눌린 그림자, 선택된 높이를 구분합니다.
- 홈·모달·레벨 선택·보드 편집·PWA 업데이트를 포함한 버튼에 공통 누름/복귀 피드백을 적용했습니다. 터치 취소, 스크롤, 키보드 입력, disabled 상태를 처리합니다. 모션 줄이기에서는 압축·반동을 줄이고 눌린 깊이를 유지합니다.
- 블록은 손가락을 조금 따라오며 압축되고, 교환 방향에 따라 늘어납니다. 낙하는 착지 압축·접촉 그림자·짧은 반짝임으로 마무리합니다.
- 폭발은 주변 블록의 국소 반응과 색·재질별 파편을 사용합니다. 망치 접촉/반동, 화살 잔상, 대포의 둥근 포탄, 셔플 궤적을 추가했습니다. 도구 충돌 이벤트는 실제 게임 판정과 같은 시점에 발생합니다.
- 효과음과 햅틱은 게임 시간으로 예약하고 일시정지합니다. 같은 프레임의 여러 충돌은 강한 신호를 우선하며, 연속 신호 간격과 음성 수를 제한합니다. 효과음과 진동 설정은 독립적이며 즉시 반영됩니다.

## iPhone

Safari에서 게임 중 임의 진동은 지원되지 않습니다. 지원하지 않는 환경에는 진동 옵션을 비활성화하고 안내합니다. 실제 iPhone 햅틱을 위한 앱 프로젝트, 번들 생성·검증 스크립트와 설치 절차는 [ios/README.md](../ios/README.md)에 있습니다. 앱 하드웨어 지원과 메인 프레임 메시지를 확인한 뒤 네이티브 출력을 허용합니다.

Xcode/iOS SDK가 없는 이 작업 환경에서는 네이티브 컴파일과 실기기 검수를 수행하지 못했습니다. 브라우저에서 네이티브 메시지 계약을 검증한 결과와 실제 모터 확인을 구분합니다.
