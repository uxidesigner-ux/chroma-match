# Chroma Royale 개인용 리뉴얼

2026-11-23. 현재 기본 화면은 조사한 Royal Match의 목표·특수 블록·장애물 규칙을 바탕으로 재구성한 개인용 게임입니다. 플레이와 편집은 브라우저 안에서 처리합니다.

## 실행

- 이 Mac: **http://127.0.0.1:5173/**
- 프로젝트의 `Launch Chroma Royale.command`를 더블클릭하면 서버와 게임을 엽니다.
- 터미널에서는 `npm run dev -- --host 127.0.0.1 --port 5173`.
- 로컬 서버가 실행 중이어야 합니다. 다른 기기의 `127.0.0.1`은 이 Mac을 가리키지 않습니다.

이번 리뉴얼은 사용자 요청으로 `main`에 반영합니다. GitHub Pages는 CI가 통과한 뒤 갱신되므로, 배포 완료 전에는 로컬 검수본과 공개 주소의 버전을 구분하세요. 같은 Wi-Fi의 iPhone 실행과 PWA 검증 결과는 [전달 안내](ROYAL-DELIVERY.md)에 기록했습니다.

처음에는 진입 화면, 이후에는 왕실 정원 홈이 열립니다. 플레이·레벨 지도·왕국 작업·설정·보드 편집 버튼을 사용할 수 있습니다. 게임 왼쪽 위 홈 버튼으로 돌아갔다가 플레이를 누르면 현재 판을 이어갑니다. 홈과 대화상자에서는 보드 시간이 멈춥니다. `?play=1`은 바로 실행, `?play=1&level=12297`은 참고 판 바로가기입니다.

## 달라진 플레이

**점수 대신 왼쪽 위 목표를 제한 이동 안에 모두 완료하면 승리합니다.** 일반 블록은 왕관·책·방패·잎이며 색과 형태로 구분합니다.

| 매치 | 생성 |
|---|---|
| 같은 색 4개 일자 | 가로/세로 로켓 |
| 같은 색 2×2 | 프로펠러 |
| 같은 색 5개 L/T | TNT |
| 같은 색 5개 일자 | 라이트볼 |

특수 블록을 누르거나 교환하면 발동합니다. 특수 블록끼리 드래그하여 교환하면 10종 조합을 사용할 수 있습니다. 라이트볼과 다른 특수 블록을 합치면 보드의 최다 색 블록을 해당 특수 블록으로 바꿉니다.

일반 블록은 이웃한 칸으로 드래그하거나 두 칸을 차례로 누릅니다. 키보드는 방향키로 칸 이동, Enter/Space로 선택·특수 블록 단독 발동, **Shift+방향키로 바로 옆 블록과 교환**, Escape로 취소합니다. 키보드로 특수 블록 두 개를 조합할 때도 Shift+방향키를 사용합니다. 유효하지 않은 교환은 이동을 쓰지 않습니다.

연쇄 중에는 영향을 받는 열만 잠깁니다. 다른 열의 일반 매치를 계속 입력할 수 있습니다. 파워업·도구처럼 넓은 영역을 바꾸는 행동은 현재 낙하가 끝나야 받을 수 있습니다. 마지막 이동을 사용한 뒤 모든 연쇄가 끝나면 승패를 판정합니다.

## 목표·기믹

| 종류 | 적용한 동작 |
|---|---|
| 상자 | 인접 매치 또는 직접 공격으로 겹 제거 |
| 선물상자 | 여러 칸이 하나의 개체. 4회 타격 후 장난감 수집 |
| 얼음 | 인접 매치로 타격하며 끝 칸부터 줄어듦 |
| 돌 | 특수 블록·도구로 3회 타격 |
| 뻐꾸기 둥지 | 이동마다 개폐, 열린 상태에서 타격하면 새 수집 |
| 다이너마이트 상자 | 같은 색 인접 매치로 작동. 보이는 목표 한 겹·일반 블록 제거, 파워업 발동 |
| 젤리 바닥 | 젤리 위 매치나 특수 효과로 바닥에 확산. 남은 칸을 채우는 목표 |

동일한 공격이 여러 점유 칸에 닿아도 같은 다칸 개체에 중복 피해를 주지 않도록 처리합니다.

## 레벨 구성

- **1–32:** 목표와 기믹을 차례로 소개하는 자체 구성 레벨.
- **33–999999:** 번호별로 크기·12가지 형상 계열·장애물 조합·이동 수를 정하는 생성 레벨.
- **12297:** 첨부 자료의 9×11 외곽, 선물상자·다이너마이트·뻐꾸기·젤리를 참고한 별도 재구성. 레벨 선택 창의 바로가기에서 엽니다.
- **직접 만든 판:** 5–12열/행을 자유롭게 편집합니다.

원작 전체 레벨 데이터는 확보하지 않았습니다. 12297의 시작 이동 32회, 선물 위치·재고 배분·시작 젤리 및 초기 일반 블록은 재구성 값입니다. 영상의 남은 목표 18·8·2·81을 플레이 가능한 참고 판에 사용했으며, 원작 시작 상태와 동일하다고 주장하지 않습니다. [레벨 데이터 상세](../src/royal/LEVELS.md), [조사 자료](research/README.md).

## 자유 설정

톱니바퀴에서 레벨 번호, 이동 횟수, 배치 번호, 속도, 무제한 이동·도구, 시작 부스터, 슈퍼 라이트볼, 효과음·진동·힌트·효과 감소를 바꿉니다.

- 이동 0은 현재 레벨의 기본 이동 수를 사용합니다. 수동 설정은 1–999회입니다.
- ‘재도전마다 새로운 블록 배치’를 끄면 동일 레벨·배치 번호·시작 부스터로 같은 시작판을 재현합니다.
- 레벨 설계와 재도전의 일반 블록 난수는 분리되어 있습니다.
- 망치·화살(가로)·대포(세로)·광대 모자(섞기)는 이동을 소비하지 않습니다. 기본 수량은 판마다 각 3개, 무제한 도구를 켜면 수량 제한이 없습니다.
- 커스텀 판에서 레벨 번호를 그대로 두고 설정을 적용하면 그 판을 유지합니다.

## 보드 편집기

하단 **보드 만들기**에서 다음 기능을 사용합니다.

1. 현재 레벨이나 저장한 보드를 가져옵니다. 가로·세로를 입력하고 ‘빈 보드’를 누르면 새 크기로 만듭니다.
2. 브러시로 보드 칸·빈 공간·젤리·장애물·일반 및 특수 블록을 놓습니다.
3. 선물상자는 1×2, 둥지와 다이너마이트는 2×2 공간을 사용합니다. 기믹이 서로 겹치면 기존 개체를 교체합니다.
4. 장애물 목표는 실제 배치 수량에 맞춰 계산합니다. 색 수집 목표는 수량 변경·추가·삭제가 가능합니다.
5. **보드 저장**, **이 보드로 플레이**, JSON 복사·파일 내보내기·파일/텍스트 가져오기를 사용할 수 있습니다.

JSON은 크기·범위·점유 중복·목표 재고·젤리 씨앗·초기 블록을 검증합니다. 오류가 있는 데이터는 현재 편집 보드를 대체하지 않습니다. 저장 가능한 커스텀 보드는 현재 1개이며, 추가 판은 JSON 파일로 보관할 수 있습니다. 저장된 원본을 불러오므로 진행 중인 낙하 상태를 편집하는 것은 아닙니다.

## 별과 왕국

캠페인 레벨 첫 완료에 별 1개와 코인 50개를 줍니다. 별 버튼을 눌러 6개의 왕실 정원 작업에 별을 쓰고, 정원을 완성하면 코인 500개를 받습니다. 보상액·작업은 개인용 구성입니다. 정원 화면은 진행도에 따라 배경의 채도·밝기가 바뀌는 간단한 메타 화면이며 원작의 개별 건축 애니메이션이나 전체 구역을 구현한 것은 아닙니다.

32레벨 이상에서는 집사의 선물 연승 단계에 따른 시작 부스터를 지급합니다. 292레벨 이상에서는 승리 10회에 슈퍼 라이트볼이 활성화되며, 활성 상태에서 실패하면 해제됩니다. 활성 전 충전 중 패배 시 승리 수를 유지하는 것은 이 프로젝트의 선택입니다. 원작의 이 세부 규칙은 추가 관찰이 필요합니다. 설정에서 즉시 사용도 가능합니다.

커스텀 보드의 승리·실패는 캠페인 별·연승·슈퍼 충전을 바꾸지 않습니다.

## 저장 및 현재 한계

설정·완료 기록·별·코인·정원 작업·연승·저장 보드는 로컬 저장소에 보관합니다. **진행 중인 판은 저장되지 않으며 새로고침하면 다시 시작합니다.** 저장 공간이 막혀 있으면 설정 화면에 안내합니다. 계정·서버·광고·결제·분석 요청을 사용하지 않습니다.

v4는 공식 이미지와 실제 홈 화면 자료를 추가로 조사해 다시 다듬었습니다. 홈은 원작 성 배경의 공개 플레이 캡처를 WebP로 변환해 사용합니다. 진입 장면은 공식 정원 그림을 세로 화면으로 편집했고, 블록·파워업·도구는 공식 이미지의 실루엣을 기준으로 투명 배경 아틀라스로 재제작했습니다. 왕 초상·목표·선물상자·보드 뒤 테라스는 제공한 12297 자료를 참고했습니다. 하단의 파란 배너, 금색 테두리와 초록 재시도 버튼도 비례·색·곡률을 조정했습니다. [출처·시각 검수](research/royal-ui-fidelity-v4.md), [생성 프롬프트 및 파일 기록](../public/royal/fidelity-assets-v4.json).

로컬 WebP 아틀라스의 실루엣 추출·크기 통일은 개발 시 한 번 수행하고, 실행할 때는 동일한 39개 이미지를 담은 `sprites-v5.json`을 읽습니다. 원본을 변경하면 `npm run sprites:build`로 팩을 다시 만들며, 일반 빌드가 원본 해시 일치를 확인합니다. 이미지 요청 실패 시 SVG를 사용합니다. 선물상자는 상태별 이미지, 나머지 다칸 장애물은 Canvas로 표시합니다. 생성·편집된 그림, 타이포그래피와 피해 단계는 원본과 픽셀 단위로 동일하지 않습니다. TNT의 반경 2/4 사각 범위, 프로펠러 우선순위, 드롭 난수, 세부 타격 판정은 자체 구현입니다. 전체 원작 장애물·이벤트·지역·레벨을 모두 포함하지는 않습니다.

이전 개인판 소스 `src/royal-main.ts`는 새 진입점에서 사용하지 않습니다. 원래 공개판은 `legacy.html`과 `src/main.ts`에 보존되어 있으며 개발 서버에서 비교할 수 있습니다.
