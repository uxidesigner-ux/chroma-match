## 이전 구현에서 확인된 차이

2026-11-23의 `docs/royal-preview/renewal-retry.png`와 `renewal-12297.png`를 직접 열어 확인했다. 다음 항목은 새 리뉴얼 이전의 기준선이다.

1. **아이콘의 재질**: 기존 SVG는 굵고 일정한 외곽선과 단순한 선형 그라데이션이 지배적이다. 원본은 면의 방향에 따라 변하는 밝기, 둥근 반사광, 아래쪽 접촉 그림자로 부피를 표현한다. 색만 맞춰서는 같은 완성도가 나오지 않는다.
2. **실패 창의 비례**: 구현의 긴 크림색 영역과 상단 장식이 화면을 크게 점유한다. 원본은 목표/부스터를 담은 크림색 내부 패널 아래에 청색 본체가 남고, 그 위에 녹색 CTA가 놓인다. 별도의 하단 선물 영역도 시각적으로 분리된다.
3. **버튼 마감**: 주 버튼에는 밝은 상단 테두리, 좁은 중간 베벨, 어두운 아래쪽 두께, 내부 면의 부드러운 반사가 필요하다. 흰 외곽선이나 한 겹의 그림자만으로는 원본의 재질이 되지 않는다.
4. **의미와 실루엣**: 벨을 체스 말 문자 `♟`로 표현하거나 목적이 다른 기호로 대체한 아이콘은 재질과 의미 모두 불일치한다. 전용 리소스로 바꿔야 한다.
5. **화면 사이 일관성**: 게임 보드, 홈의 이벤트/작업 아이콘, 부스터가 각각 다른 광원이나 서로 다른 외곽선 강도를 가지면 하나의 게임으로 보이지 않는다.

## 일치율과 반영 판단

현재 제공된 비교 자료만으로 **“99% 일치”를 인증할 수 없다.** 홈·진입 화면의 동일 버전/기기/상태 기준 이미지가 없으며, 새로 제작한 배경과 캐릭터는 원본과 같은 이미지가 아니다. 픽셀 차이를 계산하더라도 해상도·색공간·시간·배치가 정렬되지 않으면 의미 있는 수치가 아니다.

따라서 “Royal Match에 가까운 입체 재질과 UI 마감”과 “원본과 99% 동일”을 별도로 기록한다. 전자는 위 기준으로 개선·검수할 수 있다. 후자의 달성을 보고하거나 이 조건이 충족되었다고 간주해 GitHub 반영/배포를 판단해서는 안 된다.

## 새 리뉴얼 실제 검수

검수 대상은 `http://127.0.0.1:5173`에서 제공된 리뉴얼이다. 사용자 브라우저와 분리된 Chrome 테스트 컨텍스트에서 한국어·동작 감소 설정으로 확인했다. 스크린샷은 `docs/royal-preview/`에 저장했다.

### 확인한 개선

- 새 궁전 배경은 청색 지붕·금색 장식·크림색 석조·푸른 바닥의 조화를 갖추고, 입체적인 명암과 소재가 화면 전체에 이어진다.
- 홈·보드·목표·부스터가 동일한 래스터 아이콘 계열을 사용한다. 흰 사각 배경이나 눈에 띄는 알파 프린지 없이 표시되며, 작은 크기에서도 재질과 실루엣이 구분된다.
- 주 녹색 버튼의 밝은 테두리·내부 베벨·아래쪽 두께·광택이 일관된다. 레벨 번호와 주 행동이 화면에서 명확하다.
- 재시도 CTA가 크림색 패널 아래 청색 본체에 배치되었고, 집사의 선물이 실제 벨 그림으로 교체되었다. 추가 검수 후 결과 본체와 선물 영역을 분리하고, 불필요한 본문·재시작 보조 버튼을 줄였다.
- 첫 진입 캐릭터의 잘린 수평 하단을 발견해 수정 요청했고, 하단 마스크가 적용된 최종 390px/가로 화면을 직접 재확인했다.
- 가로 화면의 프로필 터치 영역이 43×43px인 것을 발견해 수정 요청했고, 44×44px로 바뀐 최종 화면에서 다시 측정했다.
- 아틀라스의 가장 큰 연결 실루엣을 기준으로 자르는 수정 후 홈을 다시 촬영했다. 최종 390px 홈의 하트 가장자리에서 이웃 스프라이트가 섞이는 현상은 보이지 않았다.

### 남은 차이와 검증 범위

1. **99% 동일 조건은 미달/미증명**: 캐릭터·궁전·아이콘은 새로 제작한 그림이다. 특히 실제 원본 홈/진입 화면을 전달받지 않아 같은 상태에서 비교할 수 없다. 완성도 개선과 원본 일치율은 같은 의미가 아니다.
2. **원본과 같은 이미지·비례는 아님**: 최종 390×844 실패 화면은 본체 약 548px, 별도 선물 영역 109px, 두 영역 사이 31px다. 구조는 제공 이미지에 가까워졌지만 동일 이미지 등록과 픽셀 비교는 하지 않았다. 표정, 타이포그래피, 버튼의 정확한 곡률과 보상 표현도 다르다.
3. **작은 화면 결과 창 수정 완료**: 최대 높이를 조정한 뒤 320px 실패 화면의 내부/표시 높이가 538/538px가 되어 이전 넘침이 없어졌다. 가로 화면은 분수 좌표의 프레임·하단 영역 경계가 모두 대화상자 경계 안에 있으며, 직접 본 최종 이미지에서 하단 테두리와 내용이 잘리지 않는다. 정수 DOM 지표에는 369/368px의 1px 차이가 남아 있으며, 실제 콘텐츠의 잘림으로 관찰되지는 않았다.
4. **실기기 미검증**: 이번 시각 검수는 Chrome의 모바일 크기 화면이다. 실제 iPhone의 Safari·홈 화면 설치·안전 영역·WebKit 차이는 이 검수만으로 통과를 주장하지 않는다.
5. **네트워크 제한 미검증**: 정상 로컬 로딩에서 모든 보이는 이미지가 완전히 로드된 것을 확인했다. 저속망·이미지 실패·장시간 플레이 성능은 별도의 테스트 결과가 필요하다.

판정: 리뉴얼의 입체 재질·버튼 마감·화면 계층 및 위 네 가지 크기의 기본 배치는 이전 구현보다 개선되었고 해당 검수 항목을 통과했다. 원본 99% 일치 조건은 충족되었다고 판정하지 않는다.
