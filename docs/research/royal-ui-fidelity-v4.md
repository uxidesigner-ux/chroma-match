## 진입 장면의 구도

공식 아트와 실제 캡처를 함께 보면 보라색 성이 왼쪽, 청색 로고 명패가 오른쪽 위, 왕·집사·개와 티테이블이 아래쪽에 놓인다. v3처럼 인물 얼굴만 크게 떠 있는 구도가 아니다. 2026 캡처의 약관 창은 운영체제/동의 흐름으로, 이 개인용 게임에 복제할 요소가 아니다. 전체 인물의 손·발·의자와 환경 접촉 그림자가 장면 안에 자연스럽게 들어가는지가 새 이미지의 검수 기준이다.

### 이번 검수에서 수정하고 재확인한 항목

- **첫 홈의 청록색 빈 화면**: 최초 공개 직후 스크린샷에서 성이 보이지 않는 문제를 직접 발견했다. 이미지 디코딩 완료 후 같은 이미지 요소를 표시하고 첫 공개를 조정한 뒤, 홈이 보이는 즉시 추가 대기 없이 다시 촬영했다. 최종 네 크기 모두 성이 보였고 이미지 `complete=true`, 원본 크기 1080×2400을 확인했다.
- **얇은 워드마크**: CSS 문자 대신 두꺼운 금색/아이보리 래스터 명패가 표시되는 것을 네 크기에서 확인했다. 인물의 얼굴이나 주요 버튼을 가리지 않는다.
- **홈 하단의 미세 넘침**: 이전 0.6–2px 버튼 경계 넘침이 없어졌다. 네 크기 모두 하단 버튼 경계가 화면 안에 있다.
- **실패 창의 보조 링크**: 아래 프레임 두께와 겹쳐 보이던 `레벨 선택` 링크가 제거되었다. 닫기와 기존 레벨 선택 경로는 남아 있다.
- **목표 그림**: 왕관 곰, 연속 무지개 원통, 앞을 보는 흰 배의 보라색 새, 불투명 보라색 사각형으로 바뀐 것을 보드 HUD와 결과 창 모두에서 확인했다. 실제 40–55px 부근 표시에서 눈에 띄는 백색/적색 잡점이나 잘린 주요 부분을 보지 못했다. 원본 아틀라스를 확대하면 가장자리 잔여 픽셀이 있으므로 원본 전체 알파가 완벽하다고 인증하지 않는다.
- **보드/HUD/배경**: 390px 보드가 화면 폭 대부분을 사용하고, 왕의 아치 프레임·차분한 회청색 바닥·버건디 선물·금색 장식이 제공 장면에 가까워졌다. 작은 320px 및 가로 화면은 보드 높이에 맞춰 축소되지만 주요 도구와 목표가 보인다.
- **결과 창**: 곡선 배너, 별도 선물 영역, 녹색 CTA와 부스터가 네 크기에서 잘리지 않는다. `overflow:visible` 장식으로 DOM의 scrollHeight가 clientHeight보다 7–9px 크지만 실제 프레임·선물 영역·버튼의 경계는 화면 안에 있으며 직접 연 이미지에서 잘림을 보지 못했다.
