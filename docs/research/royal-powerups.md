# 로얄 매치 — 특수 블록·부스터·동시 입력 조사

조사일: 2026-11-23. 공식 Dream Games 도움말을 규칙의 우선 근거로 사용했다. 아래는 확인된 외부 동작이며, 원작 소스 코드나 내부 확률표를 확보했다는 뜻은 아니다. 도움말의 상대적 업데이트 시간은 크롤링 시점에 따라 달라져 버전 번호로 취급하지 않았다.

## 1. 일반 블록과 특수 블록

일반 색 블록 외에 마법 모자에서 생성되는 보석(Gem)도 매치할 수 있다. 마법 모자 옆에서 세 차례 매치하면 보석이 생성되고, 요구 수량을 생성하면 모자가 닫힌다. 보석은 3개 이상을 맞춰 제거한다. [공식 Magic Hat 본문 확인](https://dreamgames.helpshift.com/hc/en/3-royal-match/faq/369-magic-hat/)

검색 결과에는 “Match Items / 5종”으로 보였던 FAQ 4 링크를 직접 열었을 때 실제 본문은 “How can I play the levels?”였다. 따라서 해당 검색 요약은 총 종류 수를 확정하는 근거에서 제외했다. 기본 블록·생성형 블록의 분류와 레벨별 색 구성은 별도 검증 대상이다.

| 특수 블록 | 생성 패턴 | 단독 효과 |
|---|---|---|
| Rocket / 로켓 | 동일색 4개 일자 | 로켓의 방향에 따라 가로 또는 세로 전체 |
| Propeller / 프로펠러 | 동일색 4개 2×2 | 출발 주변 칸 + 무작위 게임 요소 1개 |
| TNT | 동일색 5개 L/T | 공식 표현으로 반경 2칸 |
| Light Ball / 라이트볼 | 동일색 5개 일자 | 같은 색 아이템 전체 |

특수 블록은 **누르거나 교환하여** 발동한다. 원작 TNT의 범위를 단순히 3×3으로 구현하면 공식 설명과 다르다. 다만 “반경 2칸”만으로 대각선 포함 여부와 최종 마스크를 확정하지 않는다. 프로펠러의 “주변”도 4방향인지 8방향인지 공식 문장에는 명시되지 않았다. [공식 생성·사용 규칙](https://dreamgames.helpshift.com/hc/en/3-royal-match/faq/6-creating-and-using-the-power-ups/)

## 2. 특수 블록 조합 10종

같은 종류 두 개를 포함한 비순서 조합 전체다. 효과는 공식 조합 문서에 근거한다.

| 조합 | 공식 동작 |
|---|---|
| 로켓 + 로켓 | 해당 가로줄과 세로줄 |
| 로켓 + TNT | 가로 3줄 + 세로 3줄 |
| TNT + TNT | 반경 4칸 |
| 프로펠러 + 프로펠러 | 프로펠러 3개가 무작위 요소 3개를 타격, 출발 주변도 제거 |
| 프로펠러 + 로켓 | 주변을 제거하고 로켓을 무작위 칸으로 운반 |
| 프로펠러 + TNT | 주변을 제거하고 TNT를 무작위 칸으로 운반 |
| 라이트볼 + 로켓 | 보드에서 가장 많은 색을 로켓으로 변환 |
| 라이트볼 + TNT | 보드에서 가장 많은 색을 TNT로 변환 |
| 라이트볼 + 프로펠러 | 보드에서 가장 많은 색을 프로펠러로 변환 |
| 라이트볼 + 라이트볼 | 보드 아이템 전체 제거 및 게임 요소의 한 겹 제거 |

[공식 Power-up Combinations](https://dreamgames.helpshift.com/hc/en/3-royal-match/faq/7-power-up-combinations/?l=en)

특히 라이트볼+특수 블록은 **가장 많은 색**을 변환한다. “교환한 특수 블록의 원래 색”이나 “매번 임의 색”으로 처리하면 다르다. 최다 색 동률 처리, 변환된 로켓의 방향 결정, 같은 장애물에 겹치는 공격의 타격 횟수는 이 문서만으로 확정할 수 없다.

## 3. 시작 부스터와 게임 중 도구는 별도 체계

| 분류 | 종류 | 효과 |
|---|---|---|
| 시작 부스터 | 로켓 / TNT / 라이트볼 | 해당 특수 블록을 시작판의 무작위 위치에 배치 |
| 게임 중 도구 | Royal Hammer / 왕실 망치 | 선택 칸 또는 그 요소의 한 겹 |
| 게임 중 도구 | Arrow / 화살 | 선택 칸의 **가로줄**, 요소는 한 겹 |
| 게임 중 도구 | Cannon / 대포 | 선택 칸의 **세로줄**, 요소는 한 겹 |
| 게임 중 도구 | Jester Hat / 광대 모자 | 보드 재배치 |

게임 중 도구 사용은 이동 횟수를 소비하지 않는다. 도구의 정확한 해금 레벨, 보상 수량, 구매 가격은 여기서 확인되지 않았으므로 임의의 숫자를 원작 수치처럼 넣지 않는다. [공식 Using Boosters](https://dreamgames.helpshift.com/hc/en/3-royal-match/faq/8-using-boosters/)

## 4. 슈퍼 라이트볼

레벨 292에서 기능이 열리며, 레벨/라운드 10개를 완료하면 활성화된다. 라이트볼 효과가 2배가 되고, 실패 전까지 유지된다. 실패하면 다시 10개를 완료해야 한다. [공식 영문 Super Light Ball 본문 확인](https://dreamgames.helpshift.com/hc/en/3-royal-match/faq/234-what-is-the-super-light-ball/)

말레이어 도움말 경로의 영어 본문에는 슈퍼 라이트볼 두 개가 일반 아이템을 두 차례 지우고 게임 요소를 두 겹 제거한다는 추가 설명이 있다. 이 문장은 해당 URL을 직접 열어 확인했지만 영문 경로 본문에는 없다. 출처 간 문서 버전 차이로 표시하며 실제 최신 빌드에서 재검증한다. [공식 지역 경로 추가 설명](https://dreamgames.helpshift.com/hc/ms/3-royal-match/faq/234-what-is-the-super-light-ball/?from=AppAgg.com)

“활성화까지 반드시 10연승”과 “활성화 후 실패 시 해제”는 다른 조건이다. 공식 본문은 전자를 명시하지 않으므로 무조건 10연승으로 구현하지 않는다.

## 5. 동시 입력: 관찰 사실과 구현 가설 구분

- **외부의 직접 플레이 관찰:** Laura Taranto의 2021년 분석은 연쇄가 진행되는 동안 다른 매치를 할 수 있었다고 서술한다. 또한 프로펠러의 도착 목표가 먼저 사라지면 다른 목표로 재지정되는 행동, 일반 매치가 없을 때 특수 블록 사용을 강제하지 않고 재배열하는 행동을 기록했다. 오래된 플레이 관찰이며, 최신 빌드에서 동일한지 다시 측정해야 한다. [Deconstructor of Fun의 당시 관찰](https://www.deconstructoroffun.com/blog/2021/3/21/royal-match-the-new-king-from-turkey)
- **공식 확인 범위:** 현재 공식 파워업 설명은 프로펠러 대상을 “무작위 게임 요소”로 설명한다. 정확한 목적함수·장애물 우선순위·예약 방식은 공개하지 않는다. 따라서 “언제나 최적 목표를 고르는 AI”라고 확정할 수 없다.
- **확인하지 못한 내부 기술:** 셀 잠금 테이블, 비동기 작업 스케줄러, 상태 머신 구성, 메모리 풀의 구체 구현, RNG와 낙하 확률. 이것들은 재현 구현을 위한 설계 선택이며 Dream Games의 실제 구조로 단정하지 않는다.

재현 설계 제안은 `idle/swapping/clearing/falling` 상태를 셀·작업 단위로 추적하고, 입력 시 두 칸의 상태 및 진행 중 작업과의 충돌을 검사하는 것이다. 도착형 효과에는 대상 예약·도착 시 재검증이 필요하다. 이 문단은 **프로젝트 설계 제안**이다.

## 6. 현재 프로젝트에서 먼저 바로잡을 차이

코드는 이번 조사에서 변경하지 않았다.

1. 2×2 폭탄 생성 → 별도 프로펠러 생성·비행·도착 타격.
2. 점수+장애물 승리 → 스테이지별 목표 목록 달성 여부로 승리 판정.
3. 폭탄·파워업 조합의 범위/타격 규칙을 위 표와 비교하고 부족한 조합 추가.
4. 현재 활의 세로 타격 → 원작 화살의 가로 타격. 세로 도구는 대포로 분리.
5. 전체 보드 `busy` 잠금 → 독립된 구역의 입력을 허용하는 충돌 관리.
6. 현재 “특수 공격으로만 깨지는 얼음”은 원작 Ice와 다름. 공식 Ice는 인접 매치로 짧아지며, 특수 공격 전용은 Stone·Porcelain Piggy 등의 별도 유형이다. [공식 Game Elements](https://dreamgames.helpshift.com/hc/en/3-royal-match/section/56-game-elements-1732263700/?l=en&s=tasks-and-areas)

## 7. 코딩 전 추가 측정 목록

- TNT 단독/쌍의 실제 마스크를 모서리·경계·분리 보드에서 확인.
- 프로펠러 출발 타격 방향, 비행 중 목표 소멸, 중복 목표 예약, 남은 목표가 없는 경우.
- 라이트볼 단독 탭의 색 결정, 최다색 동률, 동일 틱에 다른 효과로 색 수가 변한 경우.
- 특수 블록이 생성되는 정확한 칸: 스와이프 도착 칸, 교차점, 연쇄 생성.
- 2×2와 일자가 겹치는 복합 매치에서 생성 우선순위.
- 로켓이 다층 장애물을 통과하는지, 각 조합이 한 요소에 몇 겹 피해를 주는지.
- 낙하 중 안정된 칸/이동 중인 칸 각각의 입력 수락·대기·취소 여부 및 이동 횟수 차감 시점.
- 마지막 이동에서 승리 조건과 후속 연쇄 종료의 판정 순서.

이 항목들을 실제 녹화와 동작 검증표로 고정하기 전에는 “완전히 동일” 판정을 내리지 않는다.
