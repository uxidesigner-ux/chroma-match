# 로얄 매치 재현을 위한 조사

> 후속 구현 안내: 아래의 “현재 구현” 비교는 조사 당시 첫 개인판을 가리킵니다. 이후 적용한 목표형 엔진·편집기·UI와 검증 결과는 [개인용 리뉴얼 안내](../ROYAL-LOCAL.md)에 기록했습니다.

조사일: 2026-11-23. 목적은 현재 Chroma Match 개인용 버전을 로얄 매치의 **확인 가능한 외부 동작**에 맞추기 위한 규칙·레벨·검증 기준을 만드는 것이다. 이번 단계에서는 게임 코드를 수정하지 않았다.

핵심 결론: 현재 구현의 점수 증가형 레벨 생성기로는 원작의 경험을 재현하기 어렵다. 목표 종류, 보드 모양, 다칸 장애물, 생성·확산 조건과 이동 횟수를 스테이지별 데이터로 분리해야 한다. 공식 규칙은 상당 부분 확인했지만, 전체 원작 레벨 배치와 내부 난수·난이도 조정 로직은 확보하지 못했다. 따라서 전 레벨이 완전히 같다고 판정할 단계는 아니다.

## 사용자 추가 확인: 레벨 12297

사용자가 기존 녹화는 **레벨 12297**이라고 확인했고, 추가 사진에도 `레벨 12297`이 표시된다. 따라서 아래 9×11 관찰값은 이 레벨의 영상 속 보드 사례다. 전체 게임의 고정 크기·고정 모양으로 사용하지 않는다.

사용자는 보드가 매 게임마다 바뀐다고 설명했다. 구현 요구사항은 레벨별 보드 크기·빈 칸·장애물·목표를 개별 데이터로 지원하는 것이다. **레벨 설계와 재시도 시 일반 블록 배치·난수는 분리**한다. 같은 레벨 재시도 때 보드 외곽까지 무작위로 바뀐다는 의미로 확대하지 않는다.

추가 사진의 재시도 창에서는 파란 곡면 배너·금색 테두리·크림색 패널·초록색 입체 버튼, 목표별 성공/실패 표시, 시작 부스터 3종 선택을 확인했다. 오른쪽 `6/10`, 하단 집사의 선물 `0/3`도 보인다. 이 한 장만으로 실패 전후 카운터 변화 규칙을 확정하지 않는다. 사진 배경에는 이동 9가 남아 있으므로 실패 원인도 이동 소진으로 단정하지 않는다.

## 근거의 구분

| 구분 | 사용할 수 있는 내용 | 제한 |
|---|---|---|
| 공식 확인 | Dream Games 도움말의 효과·조건·해금 수치 | 전체 내부 알고리즘을 뜻하지 않음 |
| 직접 관찰·사용자 확인 | 영상의 숫자·형상·동작과 추가 사진의 레벨 12297 표시 | 짧은 중간 플레이이며 게임 버전·시작 상태 미확인 |
| 외부 플레이 관찰 | 작성자가 플레이해 기록한 분석·영상 | 해당 시점의 표본, 모든 계정·최신 빌드로 일반화하지 않음 |
| 재현 설계안 | 우리가 만들 구조·도구·검증 방법 | 원작 내부 구현이나 확정된 원작 데이터가 아님 |

검색 요약보다 열린 공식 본문을 우선했다. 언어 경로·쿼리에 따라 서로 다른 내용이 잡힌 항목은 문서에서 불확실성을 표시했다.

## 게임의 기본 구조

퍼즐은 화면 왼쪽 위 목표를 제한된 이동 안에 완료하면 승리한다. 목표는 하나 이상일 수 있다. 점수는 공식 승리 조건으로 제시되지 않는다. 이동 횟수를 다 쓰기 전에 목표를 끝내지 못하면 실패한다. 따라서 “점수 부담이 없다”와 “이동 제한이 없다”는 다르다. [공식 플레이 규칙](https://dreamgames.helpshift.com/hc/en/3-royal-match/faq/3-how-do-i-play-royal-match/)

레벨 완료 → 별 1개 획득 → 별을 써서 지역 건설 과제 완료 → 지역의 모든 과제 완료 → 지역 상자와 다음 지역. 퍼즐 레벨 번호와 지역 꾸미기의 진행은 연결되어 있지만 같은 카운터는 아니다. [별](https://dreamgames.helpshift.com/hc/en/3-royal-match/faq/16-how-can-i-get-stars-1721127793/) · [과제](https://dreamgames.helpshift.com/hc/en/3-royal-match/faq/15-what-are-tasks-and-how-do-i-complete-them/) · [지역 해금](https://dreamgames.helpshift.com/hc/en/3-royal-match/faq/17-how-can-i-unlock-a-new-area/)

공식 아트 소개의 대표 일반 블록은 왕관·책·방패·잎이다. 둥근 형태, 부드러운 표면, 명확한 색과 실루엣이 강조된다. 현재 구현의 빨강 보석도 재현 기준에서는 책으로 다시 다듬어야 한다. [Dream Games 아트 소개](https://www.dreamgames.com/games/royal-match)

## 레벨이 올라가는 방식

확인된 사실은 레벨마다 목표와 이동 한도가 있고, Normal·Hard·Super Hard·Extremely Hard의 네 구분이 존재한다는 것이다. [공식 코인 안내](https://dreamgames.helpshift.com/hc/en/3-royal-match/faq/21-how-can-i-obtain-and-use-coins/)에서 이 등급을 확인했다. 조사한 공식 문서에서는 난도별 출현 간격이나 레벨 번호를 입력하면 수치가 나오는 공식을 확인하지 못했다. 자세한 해금 표와 출처는 [진행 조사](royal-progression.md)에 있다.

난이도 재현에서 조사할 축은 다음과 같다. 이것은 **레벨 기록·비교용 분석 틀**이며 Dream Games의 내부 수식이 아니다.

| 축 | 실제로 기록할 값 | 체감에 주는 영향에 대한 분석 |
|---|---|---|
| 형상 | 행·열, 빈 칸 마스크, 통로·분리 구역, 화면 전환 | 매치 후보와 특수 블록 도달 경로 |
| 목표 | 제거·수집·확산 등 목표별 잔량과 시작량 | 무엇을 해야 승리하는지 |
| 접근성 | 목표를 가리는 상자·잠금·덮개 | 목표까지 필요한 선행 행동 |
| 내구도 | 겹 수와 유효 타격 종류 | 필요한 행동 수, 도구 의존도 |
| 생성 조건 | 색 지정·주변 타격·충전 후 생성 | 매치의 위치/색 선택 요구 |
| 보충 | 스폰 지점, 낙하 경로, 포털/벨트 | 목표물·보석의 공급 구조 |
| 이동 한도 | 스테이지 시작 이동 수 | 실수 허용량 |
| 지원 상태 | 시작 부스터, 집사의 선물, 슈퍼 라이트볼 | 같은 레벨의 출발 조건 차이 |

현재 프로젝트의 `레벨당 점수 +85`, `5번째 레벨 목표 ×1.15`, `8레벨마다 이동 감소`, `모양 3종 순환`은 우리가 만든 임시 공식이다. 원작에서 수집한 난이도 곡선이 아니며, 다음 구현에서 원작 근거처럼 재사용하지 않는다. 해당 코드는 `src/game/royal.ts`에 있다.

새 레벨은 공식 안내상 2주마다 추가된다. 특정 날짜의 전체 레벨 수와 모든 레벨 파일을 확보한 것은 아니다. 스토어에서 본 특정 업데이트의 “100개 추가”를 영구적인 전체 레벨 공식으로 취급하지 않는다. [새 레벨 안내](https://dreamgames.helpshift.com/hc/en/3-royal-match/faq/40-how-can-i-play-new-levels/)

## 첨부 영상에서 확인한 구성

레벨 12297의 영상 길이는 약 6.58초이며 시작부터 진행 중인 판이다. 이 영상의 격자 경계를 세면 **9열 × 11행**이고, 1부터 세었을 때 4~5열의 5~11행이 비어 있는 아래쪽 개방형 보드로 관찰된다. 셀 좌표는 시각적 분석값이고 원작 레벨 파일에서 추출한 값은 아니다. 다른 레벨에는 해당 크기·마스크를 강제하지 않는다.

```text
111111111
111111111
111111111
111111111
111001111
111001111
111001111
111001111
111001111
111001111
111001111
```

`1`은 보드가 존재하는 위치이고 `0`은 빈 공간이다. 보드가 존재하는 칸 안에는 여러 칸을 차지하는 기믹도 있다. 이것을 일반 보석 한 칸과 동일하게 다루면 안 된다.

- 화면 목표: 곰 인형 18, 무지개 원통 8, 보라색 새 2, 보라색 타일 81. 무지개 원통은 추가 사진과 공식 장치 이미지 대조 후 다이너마이트 목표로 추정한다.
- 이동 표시는 22 → 21 → 20으로 진행된다. **22는 시작 이동 횟수가 아니라 영상 시작 시 남은 이동 횟수**다.
- 다이너마이트 상자와 새가 든 가구는 다칸 구조로 보인다.
- 하단은 망치·화살·대포·광대 모자와 설정 버튼이다. 현재 개인판의 폭탄 도구 5종 배열과 다르다.
- 레벨 번호는 사용자 설명과 추가 사진으로 **12297**로 확인했다. 원작 버전과 처음 놓인 보석·기믹 상태는 아직 알 수 없다.

공식 이미지 대조로 빨간 선물상자는 Gift Box와 강하게 대응한다. 공식 설명은 옆에서 4번 매치해 장난감을 꺼내는 것이다. 현재 구현의 “리본 1회 파괴”와 다르다. [Gift Box](https://dreamgames.helpshift.com/hc/en/3-royal-match/faq/423-gift-box/)

보라색 목표 아이콘은 Jelly와 대응한다. 공식 규칙에서 젤리는 위에서 매치해 확산시키고 보드를 덮어야 완료한다. 다만 영상 아이콘의 식별은 이미지 대조에 따른 판단이며, 클립만으로 전체 확산 판정까지 검증한 것은 아니다. [Jelly](https://dreamgames.helpshift.com/hc/en/3-royal-match/faq/392-jelly/)

기존에 병 장치로 기록했던 2×2 기믹은 **Dynamite Box**의 공식 이미지와 일치한다. 같은 색 인접 매치로 작동하며, 작동하면 보이는 목표들의 한 겹과 일반 블록을 제거하고 파워업을 발동한다. 무지개 원통 목표 아이콘이 이 다이너마이트를 나타낸다는 판단은 높은 신뢰도의 추정이며, 공식 문서에 동일한 목표 아이콘이 실린 것은 아니다. [Dynamite Box](https://dreamgames.helpshift.com/hc/en/3-royal-match/faq/371-dynamite-box/)

## 재현 개발 구조 제안

다음은 원작 소스 구조에 관한 사실이 아니라, 관찰한 동작을 구현하기 위한 제안이다.

1. **규칙 엔진:** 일반 매치, 특수 블록 생성 우선순위, 단독 탭, 10조합, 피해 전파를 화면 효과와 분리한다.
2. **칸과 기믹 계층:** 바닥 상태, 보석/특수 블록, 덮개, 여러 칸을 소유하는 기믹을 분리한다. 한 다칸 기믹은 고유 ID로 피해 중복을 관리한다.
3. **목표 이벤트:** 수집·파괴·확산·꺼내기 이벤트별 목표 진행을 계산한다. 점수를 목표의 대리값으로 쓰지 않는다.
4. **동시 입력 스케줄러:** 움직이는 칸과 영향권을 추적하며 다른 구역의 유효 입력은 허용한다. 대상이 사라진 프로펠러는 도착 시 대상을 재검증한다. 원작도 이 방식으로 구현됐다고 단정하지 않는다.
5. **레벨 데이터:** 형상, 레이어, 기믹 초기 상태, 스폰 경로, 목표, 이동 수, 난도 태그, 출처/버전/검증 상태를 JSON으로 관리한다.
6. **편집기:** 칸별 페인트, 다칸 기믹 배치, 목표 편집, 시작·재시도, JSON 가져오기/내보내기, 같은 시드 재현을 제공한다.
7. **개인 설정:** 원작 재현 규칙과 무제한 이동·도구·레벨 건너뛰기는 별도 모드로 둔다. 원작 일치 검증은 지원 기능을 끈 상태와 켠 상태를 섞지 않는다.

사용자가 언급한 2024년 논문 *The Royal Crush: Analysis of Match-3 Mechanics*는 연구자가 Godot으로 만든 범용 Match-3 툴킷과 난이도 실험을 설명한다. Dream Games가 Godot·해당 구조를 사용한다는 증거가 아니다. [논문](https://downloads.hci.informatik.uni-wuerzburg.de/2024-CoG-RoyalCrush.pdf)

## 레벨 자료 수집과 통과 기준

원작과 같다는 주장을 하려면 **레벨 번호만 맞추는 것**보다 아래 증거가 필요하다.

| 기록 항목 | 요구 증거 |
|---|---|
| 원작 버전 | 앱 버전·촬영일·플랫폼 |
| 시작 상태 | 목표/이동 수가 보이는 첫 화면, 전체 보드·다칸 기믹 |
| 지원 조건 | 시작 부스터·집사의 선물·슈퍼 라이트볼 상태 |
| 일반 규칙 | 유효/무효 교환과 차감, 매치 모양별 생성 |
| 복합 규칙 | 10개 조합, 겹치는 피해, 프로펠러 목표가 사라지는 경우 |
| 동시성 | 연쇄 중 다른 영역 스와이프, 낙하 칸 입력, 마지막 이동 |
| 목표 | 제거·수집·확산별 잔량과 완료 조건 |
| 난이도 표본 | 같은 시작 조건에서 여러 번 시도한 결과·남은 이동·도구 사용 |

제안 수집 순서는 초반 1~30의 온보딩, 31~100의 기능 확장 표본, 첨부 영상의 복합 기믹 레벨이다. 이 범위는 **우리의 수집 계획**이며 “원작은 반드시 이 구간에서 이런 기믹을 연다”는 뜻이 아니다. 현재 공개 영상 목록은 찾았지만 전 프레임을 확인한 원작 1~100 레벨 데이터셋은 아직 없다.

이번 조사로 확정할 수 없는 항목은 전체 레벨 좌표·최초 등장표, 난수 시드와 스폰 가중치, 실패 이력에 따른 개인별 조정 여부, 정확한 타겟팅 우선순위, 프레임별 애니메이션 수치다. 고정 5레벨 주기나 실패 횟수에 따른 확률 조작을 사실처럼 만들지 않는다.
