# v8 목표를 향하는 프로펠러와 발사형 라이트볼

2026-11-23. 프로펠러의 목적지와 라이트볼의 발사 원점·도착·파괴 관계가 분명하게 보이도록 개선했습니다.

## 프로펠러

주변 칸을 제거한 뒤 현재 남은 목표에 대한 후보 목적지의 기여도를 평가합니다. 목표 잔량, 마지막 타격으로 수집할 수 있는지, 남은 장애물 층, 선물상자의 장난감 수, 특수 공격만 통하는 돌, 퍼뜨릴 수 있는 젤리를 고려합니다. 완료한 목표와 닫힌 뻐꾸기 둥지는 우선 대상이 아닙니다.

로켓·TNT를 운반할 때는 착륙점뿐 아니라 실제 행·열·폭발 범위가 줄일 목표를 합산합니다. 큰 장애물의 여러 칸을 별개 목표로 중복 계산하지 않습니다. 다른 프로펠러가 이미 예약한 타격도 반영해 같은 마지막 한 겹에 여러 대를 낭비하는 것을 줄입니다. 비행 중 대상이 사라지면 현재 판에서 다시 평가합니다. 같은 기여도의 후보에만 기존 시드 난수를 사용합니다.

이는 현재 판의 목표를 우선하는 유한한 평가 로직입니다. 이후의 무작위 보충 블록까지 예측해 승리를 보장하는 최적 풀이기는 아닙니다. 원작의 세부 AI를 복제했다고 주장하지 않습니다. [공식 도움말](https://dreamgames.helpshift.com/hc/en/3-royal-match/faq/6-creating-and-using-the-power-ups/)은 프로펠러의 목적지를 무작위 게임 요소로 설명합니다.

## 라이트볼

단독 탭은 현재 가장 많은 일반 블록 색을, 일반 블록과의 교환은 상대 블록 색을 선택합니다. 선택된 모든 칸에 실제 도착 예정이 있는 광선을 생성합니다.

1. 원래 구체 위치에서 충전하고 에너지 고리와 빛을 모읍니다.
2. 같은 색의 대상들을 표시하고 구체에서 각 블록으로 광선을 발사합니다.
3. 개별 광선의 머리와 잔광이 이동합니다. 대상 수가 많아도 멀리 있는 칸을 생략하거나 같은 시점에 몰아 터뜨리지 않습니다.
4. 각 광선이 도착하는 엔진 시간에 해당 블록을 제거하고 충돌 섬광·파편·효과음을 냅니다.
5. 마지막 도착 후 낙하와 연쇄가 진행됩니다.

구현 시간은 충전 0.24초, 한 차례 광선 발사·도착 최대 0.72초입니다. 원작에서 측정한 값은 아닙니다. 렌더러와 엔진은 동일한 `rays` 일정으로 표시와 판정을 처리합니다. 동작 줄이기에서는 이동 광선 대신 대상 표시를 유지하며 판정은 같습니다.

라이트볼+다른 특수 블록은 각 광선이 도착한 칸에서 변환을 보여준 뒤 발동합니다. 먼저 도착한 특수 블록이 다른 대상의 광선 도착 전에 그 블록을 없애지 않도록 순서를 보호합니다. 라이트볼 두 개는 전체 판을 대상으로 하되 큰 장애물은 한 차례에 한 겹만 깎습니다. 반복 공격은 실제 남아 있는 대상에만 다시 발사하며 빈 칸에 폭발을 만들지 않습니다. 중간에도 원점 구체를 유지합니다. [공식 조합 규칙](https://dreamgames.helpshift.com/hc/en/3-royal-match/faq/7-power-up-combinations/)

효과음은 충전 상승음·발사음·첫 강한 충돌·후속 짧은 도착음으로 구분합니다. 진동 지원 환경에서는 대응하는 촉감을 요청하고 과도한 연속 출력은 제한합니다. 네이티브 iPhone 햅틱의 실제 기기 검수는 기존 [앱 준비 안내](../ios/README.md)의 남은 항목입니다.

## 검증

- 단위 테스트 344개 통과: 목표 선정 17개, 광선 일정·색 선택·변환·큰 장애물·프레임 간격 독립성·대형 보드·빈 칸 재발사 방지 8개, 피드백 21개 포함.
- UI 테스트 53개 통과. 라이트볼의 0.7/1.4배속 도착·파괴 일치, 설정/홈에서의 일시정지·복귀, 실제 목표로 날아가는 프로펠러 검사를 추가했습니다.
- 스트레스 검사 14,400개, 특수 생성 39,708회에서 생성 시점·중복 제거·정착·블록 ID 검사 통과.
- 스트레스 검사는 실제 목표 AI 7,200개와 기존 코너 착륙 경합을 고정 재현한 7,200개를 구분합니다. 실제 AI의 넓어진 운반 범위로 예약된 칸은 입력을 정상 거절하며, 가능한 다른 일반 매치는 공개 입력 API로 찾아 검수합니다.
- Swift 구문·프로젝트 검사와 iPhone용 오프라인 번들 갱신 완료. Xcode/iOS SDK를 이용한 네이티브 빌드는 아직 수행하지 못했습니다.
