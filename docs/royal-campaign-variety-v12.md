# 8×9 캠페인 다양성·난도 개선

2026-11-23. 생성 캠페인(33판 이후)의 모양·장애물 배치·난도 곡선을 함께 변경했다. 초반 구성 레벨 1–32, 영상 참고판 12297, 사용자 보드의 규칙과 크기는 유지한다.

## 보드와 장애물

- 최대 8열 × 9행 안에서 연결된 실제 마스크 952개를 순환한다. 12개 모양 계열에 크기·방향·가장자리 변형을 조합하고, 중복 마스크를 제거했다. 연속한 생성 레벨의 모양은 반복하지 않는다. 952판 뒤에는 모양을 재사용하지만 레벨별 시드에 따라 장애물과 블록 구성은 달라질 수 있다.
- 장애물은 두 군집, 가로 띠, 중앙, 가장자리, 대각선, 교차 군집의 여섯 배치 규칙을 사용한다. 여러 칸을 차지하는 기믹도 보드 안에 온전히 배치한다.
- 장애물을 놓을 때마다 남은 일반 블록 공간의 연결성, 최소 20칸, 비어 있는 3×3 영역을 유지한다. 일반 블록 공간의 70% 이상에 직선 3개 또는 사각형 매치를 만들 수 있는 지형을 확보한다. 인접 매치형 장애물은 이러한 공간과 접해야 한다.
- 젤리는 실제 매치가 가능한 두 위치에서 시작한다. 목표는 배치된 장애물·재고·젤리로 다시 계산하고 최대 4종으로 제한한다.

## 난이도

33판부터 10판 단위로 회복 2판, 보통 5판, 어려움 2판, 마지막 도전 1판을 배치한다. 네 번째 묶음의 마지막 도전은 최고 난도다. 각 판을 무조건 이전 판보다 어렵게 만드는 대신, 쉬어 가는 판을 포함해 장기적인 난도가 올라가게 한다.

난도 성장은 약 10만 판까지 완만하게 이어지고 그 뒤에는 상한을 유지한다. 장애물 점유율·내구도·새 재고·기믹 수를 조정하며, 회복 판은 두 기믹과 낮은 밀도를 사용한다. 배치된 실제 타격 작업량, 특수 블록 전용 바위, 번갈아 열리는 둥지, 젤리 작업량을 바탕으로 이동 횟수도 조정한다. 다이너마이트의 보조 폭발은 난도 완화로 반영한다. 실패 횟수나 결제 여부로 보드를 변경하지 않는다.

이 수치는 원작의 내부 난도나 사람의 승률을 복원한 값이 아니다. 구조적으로 성립하는 퍼즐과 완만한 작업량 증가를 검증하는 자체 생성 규칙이다.

## 엔진 검수

[독립 감사 결과](royal-preview/v12-varied-campaign/engine-audit.json)는 기존·새 생성기를 34개 레벨 × 3개 블록 시드 × 2개 자동 조작 정책으로 비교한다. 입력 실패·시작 보정 파워업·연쇄 정착 실패는 없었다. 새 생성기의 목표 지향 정책에서는 모든 개별 목표에 진행이 있었고, 도구 없이 생성한 특수 블록으로 바위도 타격했다. 별도 1,680개 레벨에서는 지형·접근성·크기 조건 위반이 없었다.

실제 타격량/이동 수는 초반 0.739에서 중간 0.836, 후반 1.032, 상한 부근 1.191로 증가했다. 같은 테마·난도·회복 여부를 맞춰 표본이 충분한 20개 비교군에서도 증가했다. 이 비율은 구조적인 압력 비교이며 사람의 성공률이 아니다.

빌드·단위 테스트 361개·게임 UI 회귀 검사 63개·Chrome/WebKit 배포 검수 4개를 통과했다. 999999판을 실제 도구와 일반 이동으로 완료한 뒤 1000000판으로 진입하는 흐름도 포함한다. iPhone 래퍼용 오프라인 묶음도 갱신하고 정적 검사를 통과했으며, Xcode가 없어 네이티브 컴파일·기기 진동은 이번 변경에서 검증하지 않았다.
